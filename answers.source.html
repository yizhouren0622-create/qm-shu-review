19. 归一化与概率（12 分）

解题思路课件标准四问：先归一 → 写 $|\psi|^2$ → 找最大 → 积一段区间。用 $\sin^2$ 在整数个半波上平均为 $1/2$。

解题模式「平方可积定 $A$ → $w=|\psi|^2$ → 求导或对称性找最大 → 定积分求区间概率」。

（1） $$\int_0^a A^2\sin^2\frac{\pi x}{a}\,\mathrm dx=A^2\int_0^a\frac{1-\cos(2\pi x/a)}{2}\,\mathrm dx=A^2\cdot\frac{a}{2}=1$$ $$\Rightarrow\quad A=\sqrt{\frac{2}{a}}\quad(\text{取正}).$$

（2） $w(x)=\dfrac{2}{a}\sin^2\dfrac{\pi x}{a}$（$0\le x\le a$，外为 0）。$\sin$ 在半个拱的顶点 $x=a/2$ 最大，故 $w$ 也在 $x=a/2$ 最大。

（3） $[0,a/2]$ 正好半个拱，左右对称， $$W=\int_0^{a/2}w(x)\,\mathrm dx=\frac12.$$

  1. Normalize: $1=A^2\int_0^a\sin^2(\pi x/a)dx=A^2a/2$, hence $A=\sqrt{2/a}$.
  2. $w(x)=(2/a)\sin^2(\pi x/a)$ inside the interval, zero outside. Its maximum occurs at $x=a/2$.
  3. By symmetry, $P(0\le x\le a/2)=\int_0^{a/2}w(x)dx=1/2$.

Probability is an integral of the density, not an integral of the amplitude.

20. 一维无限深方势阱（12 分）

解题思路课件四步：列方程 → 边界条件 → 定态含时形式（本题只要空间本征） → 归一化。壁无限高 → 外面 $\psi=0$ → 两端必须为零。

涉及公式 $$-\frac{\hbar^2}{2m}\frac{\mathrm d^2\psi}{\mathrm dx^2}+V\psi=E\psi,\qquad V=0\ (0<x<L).$$ 令 $k=\sqrt{2mE}/\hbar$，通解 $\psi=A\sin(kx+\delta)$。

解题模式「阱内自由粒子方程 → $\psi(0)=\psi(L)=0$ 卡出 $kL=n\pi$ → $E_n\propto n^2$ → 归一化得 $\sqrt{2/L}$」。不要和对称阱 $|x|<a$（能量差因子 4）混用。

（1） 阱内 $V=0$： $$-\frac{\hbar^2}{2m}\psi''=E\psi.$$ 无限高壁作为有限势垒的极限，要求阱外波函数为零，并给出端点边界条件，所以 $\psi(0)=\psi(L)=0$。

（2） $\psi(0)=0\Rightarrow\delta=0$；$\psi(L)=0\Rightarrow\sin(kL)=0\Rightarrow kL=n\pi$，$n=1,2,3,\ldots$（$n=0$ 使 $\psi\equiv0$，弃去）。 $$E_n=\frac{\hbar^2 k^2}{2m}=\frac{n^2\pi^2\hbar^2}{2mL^2}.$$ 归一化 $\displaystyle\int_0^L|\psi|^2\mathrm dx=1$ 得 $$\psi_n(x)=\sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L}\qquad(0<x<L).$$

  1. Inside: $-\hbar^2\psi''/(2m)=E\psi$. Infinite walls impose Dirichlet conditions $\psi(0)=\psi(L)=0$ as the infinite-barrier limit; the wave function vanishes outside.
  2. Write $\psi=A\sin kx+B\cos kx$, $k^2=2mE/\hbar^2$. The first boundary sets $B=0$; the second gives $kL=n\pi$.
  3. $n=0$ is the zero function, so $n=1,2,\ldots$ and $E_n=n^2\pi^2\hbar^2/(2mL^2)$.
  4. Normalization gives $\psi_n=\sqrt{2/L}\sin(n\pi x/L)$ inside, zero outside.

The width here is $L$. A well on $[-a,a]$ has width $2a$.

“Forbidden” refers to a selection rule for a specified transition mechanism.

选择定则要注明跃迁机制或近似，这里通常指电偶极近似。相应矩阵元非零称为允许跃迁；在此近似下矩阵元为零称为禁止跃迁。磁偶极、电四极或多光子等其他机制仍可能产生较弱跃迁。“禁止”不等于一切机制下绝对不发生，完整体系仍须满足角动量守恒。

Selection rules refer to a specified interaction or approximation, usually electric-dipole transitions here. An allowed transition has a nonzero matrix element in that approximation. A forbidden transition has a zero matrix element there, but weaker mechanisms such as magnetic dipole, electric quadrupole or multiphoton processes may contribute. Angular momentum is still conserved by the complete system; “forbidden” does not mean conservation laws stop applying.

  3. 测量假设： 单次测量只得到该算符的某个本征值；若 $\psi=\sum c_n\phi_n$，得到 $\lambda_n$ 的概率是 $|c_n|^2$（已归一）。
  4. 平均值假设： $\overline F=\int\psi^{*}\hat F\psi\,\mathrm dV$（可不是任何一个本征值）。
  5. 演化假设： 状态随时间的变化由薛定谔方程决定。
  1. A state is described by a wave function (probability amplitude).
  2. Observables correspond to linear Hermitian operators on appropriate domains.
  3. Measurement outcomes are eigenvalues; for a normalized expansion $\psi=\sum_n c_n\phi_n$, probabilities are $|c_n|^2$ (sum within a degenerate eigenspace).
  4. The mean is $\langle F\rangle=\int\psi^*\hat F\psi\,dV$, which need not be an eigenvalue.
  5. Time evolution obeys the Schrödinger equation.

23. 角动量叠加态（5 分）— 含判断用到的本征值

解题思路球谐函数 $Y_{lm}$：$L^2$ 本征值 $\ell(\ell+1)\hbar^2$，$L_z$ 本征值 $m\hbar$。看叠加里两个分量的本征值是否相同。

涉及公式 $$\hat L^2 Y_{\ell m}=\ell(\ell+1)\hbar^2 Y_{\ell m},\qquad \hat L_z Y_{\ell m}=m\hbar\,Y_{\ell m}.$$ 本题：$Y_{11}$ → $\ell=1,m=1$；$Y_{21}$ → $\ell=2,m=1$。

中文。

  1. $L^2$：一个分量本征值 $1\cdot2\hbar^2=2\hbar^2$，另一个 $2\cdot3\hbar^2=6\hbar^2$，不相等 → 不是 $\hat L^2$ 的本征态。
  2. $L_z$：两个都是 $m=1$，本征值都是 $\hbar$ → 是 $\hat L_z$ 的本征态。
  3. 因此测 $L_z$ 只可能得到 $\hbar$。

（本卷不要求概率。若继续算：未归一系数模方 $1/9$ 与 $4/9$，总 $5/9$，归一后概率 $1/5$ 与 $4/5$；$\langle L^2\rangle=\frac15\cdot2\hbar^2+\frac45\cdot6\hbar^2=\frac{26}{5}\hbar^2$。）

The components have different $L^2$ eigenvalues, $2\hbar^2$ and $6\hbar^2$, so their superposition is not an $L^2$ eigenstate. Both have $m=1$, hence $\hat L_z\Psi=\hbar\Psi$ and the only $L_z$ result is $\hbar$. Optionally, normalized weights are $1/5,4/5$, giving $\langle L^2\rangle=26\hbar^2/5$.

24. $\delta$ 函数积分（5 分）

解题思路先把 $\delta$ 的自变量凑成 $(x-x_0)$ 形式，用缩放性质提出系数，再用筛选性质取出 $f(x_0)$。

涉及公式 $$\delta(ax)=\frac{\delta(x)}{|a|}\ (a\neq0),\qquad \int_{-\infty}^{\infty}f(x)\delta(x-x_0)\,\mathrm dx=f(x_0).$$

解题模式「因式分解自变量 → 缩放 $\delta(ax)=\delta(x)/|a|$ → 筛选得 $f(x_0)$」。

中文过程。 $$\delta(-2x+4)=\delta\big(-2(x-2)\big)=\frac{\delta(x-2)}{|-2|}=\frac{\delta(x-2)}{2}.$$ 因此 $$\int_{-\infty}^{\infty}f(x)\,\delta(-2x+4)\,\mathrm dx=\int f(x)\cdot\frac{\delta(x-2)}{2}\,\mathrm dx=\frac{f(2)}{2}.$$

Factor the argument: $\delta(-2x+4)=\delta(-2(x-2))=\delta(x-2)/2$. Use $\delta(au)=\delta(u)/|a|$ and $\int f(x)\delta(x-x_0)dx=f(x_0)$ to obtain $f(2)/2$. Omitting the absolute-value scale factor is a common error.
