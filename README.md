# 量子力学复习站（上大微电子 · 课件范围）

静态网页：复习课、模拟卷、参考答案详解。手机 / 平板 / 电脑浏览器均可访问。

## 本地预览

用浏览器打开 `index.html`，或在本目录执行：

```bash
python -m http.server 8080
```

访问 `http://127.0.0.1:8080/`。

## 重新生成页面

若改了 `*.source.html`，运行：

```bash
python build_site.py
```

## 范围说明

仅含陈子健课件 Chapter 01–03 量子部分；不含固体物理，不含教材独有、课件未讲内容。
