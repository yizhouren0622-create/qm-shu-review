# 量子力学复习站 · Quantum mechanics review

上海大学微电子 Chapter 01–03 课件复习站。保持暖色纸张排版，支持中文、English 和中英对照，语言偏好仅保存在本机浏览器。

## 本轮试卷

- `past-paper.html`：用户提供《课堂检测(1)》的17道题，按原顺序完整转录；提示、双语参考解析、易错点和逐题课件/教材出处为新增内容。原卷PDF保存在 `assets/classroom-check.pdf`，教材和课件PDF不随网站公开。
- `exam.html`：新模拟A，贴近基础概念、辨错、短对易证明与无限深阱计算。
- `exam-ch3.html`：新模拟B，保留旧网址，扩展课件内的概率流、周期箱、δ分布与角动量测量；不再是旧版纯第3章卷。
- `answers.html`：与新模拟A共用数据的答案集合；B卷答案与原卷解析分别在各自题后。
- `archive-exam.html`、`archive-exam-ch3.html`、`archive-answers.html`：旧版补充练习存档，首页折叠入口可访问。

每套主卷均为8填空、4选择、4简答、1道计算。模拟卷按40/20/20/20计分，共100分。原卷前三类的“5′”按每小题5分作计分解释，并在页面明确说明该解释与原PDF的标注区别。

提示和答案默认分别收起。可打印纯题目或含解析版，打印结束恢复此前展开状态。题目、提示、解答和引用统一来源，避免答案集合与试卷不同步。

## 依据与内容边界

解析以提供的Chapter 01–03课件为主，周世勋原著、陈灏修订《量子力学教程》第3版为辅。课件页码使用PDF物理页序；教材同时给书内页码和PDF页码。原卷出现的康普顿效应在所供课件中未定位到，单独标为教材辅助。短答先给课堂可用答法，再解释适用条件；没有把广义的“能量离散/动量连续”等不严谨说法写成普遍结论。

新卷是按这份拼卷的考法编写的学习材料，不是官方试卷、官方答案或对未来考试内容的预测。复习课及课件例题仍保留中文全文与英文要点；公式卡片、三套主卷及其解析提供中英文内容。

## 本地预览

```bash
python -m http.server 8080
```

打开 `http://127.0.0.1:8080/`。现代浏览器原生MathML显示公式，不依赖外部公式服务；离线阅读需保存页面以及assets、fig资源。

## 重新生成

```bash
python -m pip install -r requirements-build.txt
python build_site.py
```

主卷编辑 `data/papers.json`，逐题引用编辑 `data/paper-sources.json`。`build_exams.py` 先生成三套主卷及A卷答案集合的源页，`build_site.py` 再注入共用导航并预渲染公式。其他页面编辑相应 `*.source.html`。生成文件不宜直接编辑。

历史 `data/exams.json` 仅保留旧版题目记录，主卷生成不再读取它。旧版存档由对应 `archive-*.source.html` 保留。
